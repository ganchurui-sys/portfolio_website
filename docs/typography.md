# 网站字体规范

## 字体分工

- 英文展示大标题：保留现有 `Century Gothic Web` 斜体。用于 ABOUT ME、URBAN DESIGN、AIGC PRACTICE、CONTACT ME 等展示文字，不用于中文长段落。
- 正文与内容标题：统一使用 `--font-body`。英文优先 Arial / Helvetica；中文在 macOS / iOS 优先苹方（PingFang SC），Windows 优先微软雅黑（Microsoft YaHei），其他环境回退到已安装的 Noto Sans CJK SC 或系统无衬线字体。
- 中文采用正体，正常字距，不套用英文展示标题的负字距与斜体。
- 当前中文采用系统字体回退，并非嵌入式字体，因此不同操作系统的字形会略有差异。若要求所有设备完全一致，后续需确定并嵌入同一款获授权的中文 Web 字体。

## 排版层级

以下像素值以浏览器默认根字号 16px 为基准。

| 层级 | 字号 | 字重 | 行高 / 字距 |
| --- | --- | --- | --- |
| 首页英文展示标题（现有桌面规则） | `clamp(46px, 6.8vw, 112px)` | 500 | ABOUT / AIGC 为 0.86，URBAN / CONTACT 为 0.79；字距 -0.075em |
| 中文内容标题 | `clamp(1.5625rem, 2vw, 2.375rem)`，即 25–38px | 700 | 1.4 / 0 |
| 实习经历条目标题（公司与职位） | `clamp(1.125rem, 1.3vw, 1.375rem)`，即 18–22px | 700 | 1.5 / 0 |
| 中文正文 | `clamp(1rem, 0.9vw, 1.125rem)`，即 16–18px | 400 | 1.8 / 0 |
| 模块导航（现有规则） | 14–15px | 700 | 1.4 / 0.07em |
| 辅助编号（现有规则） | 12px | 常规或 700，按层级 | 编号使用等宽数字 |

中文段落间距与标题下间距均为 1.5rem（默认 24px），正文左对齐。PROFILE 正文颜色为深灰 `#4A4A4A`，标题保持黑色。字号随视口变化，不因页面不同而另设一套中文正文样式。

实习经历同样采用 16–18px 深灰正文、1.8 倍行高；职责关键词与成果数字加粗。日期加粗并使用等宽数字。条目间以浅灰细线及上下各 32px 留白分隔，不使用卡片边框。

About 黑底试验版通过独立主题覆盖颜色：背景 `#000000`、标题 `#F5F5F5`、正文 `#B8B8B8`、未选中模块标题 `#999B9B`、分隔线 `#2C2C2C`。字号和字体规则不变；其他页面仍沿用原浅色主题。人物视频暂保留源素材的白底。

桌面宽度达到 1280px 时，四个模块共用的右侧内容区统一左移 `clamp(64px, 6vw, 112px)`，并增加同等宽度，右边界保持不变；内容最大宽度为 780px。内容标题及经历条目标题保持单行，正文字号与换行规则不变。窄屏保留自然换行，避免缩小文字或截断标题。

## 本次应用范围

- PROFILE 已替换为中文标题和两段介绍，并应用上述中文标题、正文规则。
- 全局正文及 About 页面共用 `--font-body`；尺寸、行高和段距变量定义在 `app/globals.css`。
- 保留现有首页英文展示标题、模块导航、其他模块内容、布局与动画。
- 顶部索引目前另有桌面与移动端的小字号规则；它们未在本次改稿中改版。后续全站字体统一时，应单独收敛导航字号，而不是将正文缩小到索引字号。
